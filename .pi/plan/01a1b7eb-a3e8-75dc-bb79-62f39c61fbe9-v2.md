## Goals

1. [/] goal: 训练并验收能跑通新赛道的同一模型
   - subtle failure mode: 局部出生、绕过障碍、修改赛道降低难度、重复挑选测试种子，或用不同模型录视频，看起来成功但不是从起点完成全程。
   - discriminator: 冻结并记录赛道和模型哈希；100 个独立 `pose-v1` 回合从起点出发，至少 91 次到达 `x ≥ 100m`，全程 `|y − 4.0| < 1.9m`，按场景规则经过轮胎、楼梯、独木桥和限高架且无违规绕行。保存逐回合结果、失败原因和配置。成功视频须由同一模型、匹配 decoder 和验收中的成功种子重放核验。
   - tasks:
     1. [/] 固定验收场景并检查碰撞、观测、桥面与限高架的物理可行性；若修复物理错误，保留旧版、记录差异和哈希，不暗中降低难度。
     2. [/] 保留现有可用模型和匹配先验；检查轮胎、楼梯等失败机制，持续设计和测试奖励、动作、模型结构与课程，兼顾起步和全程能力。
     3. [/] 每轮训练前记录配置和晋级条件；失败即停止该试验、保留记录，从合适的未失败检查点换方案继续，不自动续训失败试验。
     4. [ ] 候选具备晋级证据后，用未参与训练及调参的独立种子做全程验收；未达标则继续实验。达标后制作并核验成功视频。

## Pseudocode

```py
scene ← freeze_and_hash(approved_material_course)
base ← load_usable_policy_with_matching_decoder()
while not accepted:
    observations ← diagnose_failures(base, scene)
    design ← choose_reward_structure_and_curriculum(observations)
    gate ← record_pilot_budget_and_retention_checks(design)
    candidate ← train_versioned(base, design, gate)
    if pilot_failed(candidate, gate):
        preserve_logs(candidate)
        revise_hypothesis()  # 不继续失败的试验
        continue
    if not full_course_candidate(candidate):
        base ← select_validated_candidate(candidate, base)
        continue
    episodes ← evaluate_100_independent_pose_v1(candidate, scene)
    if valid_successes(episodes) < 91:
        preserve_logs(episodes)
        continue
    video ← replay_verified_success(candidate, scene, episodes)
    accepted ← video_matches_episode(video, episodes)
```

## Learnings

- 有效轮速探索均值约 0.26，但本轮仍丢失低轮胎通过样本；不能续训失败的最终权重。

- 轮速探索基础标准差 1.5 经软门缩放后样本均值仅约 0.169，需以实际记录而非配置判断探索。

- 单独放慢或加快轮胎区指令不能解决当前首排轮胎碰撞。

- 直接在行进中蹲身无法复制停车蹲伸产生的高跳，须协调推进、支撑和腾空时序。

- 模拟机器人能产生较高弹跳，但着陆发生小腿或轮胎碰撞，跳高不等于有效越障。

- 继续切换固定偏置仅小幅推进第一排轮胎，需尝试状态反馈或不同动作先验。

- 成功学会停车及重启仍会回到原轮胎碰撞瓶颈，下一阶段必须学习实际接触后的连续通过。

- 模型已学会局部恢复前进，但一次未见起跑失败，且 x≥24.2m 仍不是跨越轮胎。

- 新数据包含恢复后重启轮驱的样本，但是否能闭环学习须用未见种子检验。

- 教师可结束停车，但 x=24.2m 仍在轮胎前，不能当作越胎示范。

- 教师的永久停车被模型学会，必须增加结束停车和有效通过的监督或奖励，不能把局部抬轮当成目标完成。

- 第二阶段能在第一排轮胎前推进一些，但固定偏置仍未找到完整轮胎动作，不能用作成功示范。

- 闭环局部技能通过只证明停车抬轮与短程起步，模型尚未穿越轮胎或完成赛道。

- 留出数据上的动作误差不能证明机器人闭环动作有效，必须以未参与训练的真实仿真回合判定。

- 仅该新数据版本采用显式记录的起步渐升；旧数据和验收默认调度未被覆盖。

- 原地形和模型不变时平滑起步改善了短程稳定性，但此导航调度尚未用于或证明全程验收。

- 这 5 个起步失败均为右后小腿触地，终止时俯仰约 -0.62 至 -0.73rad，需先改善起步稳定性。

- 稳定基础策略在部分未见起点种子约第 76 步即触地，3 个起点回合不足以证明起步鲁棒。

- 配置的 `aux_std=2/3` 只影响初始采样；更新时的 clamp 会降低其值，后续实验需记录有效而非仅配置的标准差。

- 新动作能复现停车辅助技能，但仍需训练并验证模型自主触发；这些回放不是训练模型的成绩。

- 新轮速动作与动作限幅已随 checkpoint 记录；冒烟只验证接口和梯度，不证明学会抬轮或越障。

- 人工停车动作不能由现有 29 维 actor 独立表达，新增控制必须随 checkpoint、训练及验收一致记录。

- 唯一被反事实放行的种子随后仍撞击终止，记录的该轮毂接触最大法向力约 376N，不能据此判为安全接触。

- 最远动作终止于前足电机外壳接触轮胎，须区分实际几何碰撞与终止策略再作诊断。

- 最远人工动作约到 x=24.694m，虽抬高前轮但头部撞上轮胎，需控制机身俯仰和另一侧支撑。

- 10/10 仅证明停车人工动作在局部复现；需要真实轮胎接触与移动通过验证，不能视为模型通过赛道。

- 当前最佳诊断的直立轮心峰值约 0.312m，但它使用轮速人工干预，尚非策略或越胎成功。

- 四轮经过轮胎走廊不等于接触物料，验收须同时记录实际轮胎接触。

- 最佳单轮动作释放后末帧直立，但连续恢复未被原脚本正确检查，且未达到预设 0.252m 或越胎。

- 单腿支撑可实现几何抬轮，但出现小腿触地或另一前腿撞轮胎，需协调落脚与支撑而非仅提高抬脚。

- 两条前腿同时缩短时机身由约 0.334m 降至 0.25m，而轮心仍约 0.087m；下轮检查单腿支撑切换。

- 所测试停车抬腿动作中前轮中心最高仅约 0.0885m，静态可达性并未转化为动态抬轮。

- 冻结基础策略保住了 3/3 起点，但本轮局部通过率退化，说明低难度课程也不能仅靠当前奖励和探索保证迁移。

- `tire_v1` 仅允许冻结目标场景；低障碍课程必须显式标识并单独验证哈希，不能绕过目标场景保护。

- 已证实可训练的残差和较宽腿部动作本身仍不足以在当前采样与奖励下学会越胎。

- 明确规范化 float32 限幅边界后，放宽物料动作范围的零残差初始策略可精确保留原轨迹；尚未证明训练后保留。

- float32 的 ±0.2 与环境 float64 限幅相差约 3e-9，接触动力学会放大该差异；不可称旧、新 rollout 位姿一致。

- v2 用非零软门和零初始化残差头兼顾起始确定性输出一致及残差头梯度；冒烟不证明越障能力。

- 原残差门 `clamp((sigmoid(-6)-0.5)/0.35)` 初始为零且梯度为零，不能假设该结构能学会越障。

- 所测试的先验轨迹、相位与切换位置组合最远约 24.518m；这只排除所测 96 组，不证明 bound 不可行。

- 更大的对称腿部偏置及其时序变化仍未形成有效越障；不能据此排除不对称足端协调或不同控制结构。

- 上一轮最佳诊断在第一排轮胎处因前足电机外壳碰撞终止；最大身体 x≈24.922m，不能当作越障。

- 新 checkpoint 若缺少材料动作限制元数据，严格验收拒绝加载，避免训练与验收使用不同裁剪规则。
